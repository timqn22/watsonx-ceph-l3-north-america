# Viewer Guide

This project includes two web viewers for exploring the bidirectional relationship between Redmine issues and GitHub PRs.

## 📊 Two Viewers Available

### 1. PR Results Viewer (`pr_results_viewer.py`)
**Shows: GitHub PRs → Similar Redmine Issues**

- **Port:** 5001
- **URL:** http://localhost:5001
- **Data Source:** `pr_issue_links.json`
- **Purpose:** View GitHub PRs and find related Redmine issues
- **Features:**
  - Search PRs by number or title
  - Filter by PR state (Open/Closed)
  - Shows all similarity scores
  - Auto-refreshes every 60 seconds

### 2. Issue-PR Viewer (`issue_pr_viewer.py`)
**Shows: Redmine Issues → Similar GitHub PRs**

- **Port:** 5002
- **URL:** http://localhost:5002
- **Data Source:** `issue_pr_links.json`
- **Purpose:** View Redmine issues and find related GitHub PRs
- **Features:**
  - Search issues by number or subject
  - **Only shows PRs with similarity > 85%**
  - **Limited to 50 issues per page**
  - Auto-refreshes every 60 seconds

## 🚀 Quick Start

### Step 1: Backfill PR Vector Database
If you ran the PR monitor before the vector database feature was added, backfill existing PRs:

```bash
python3 backfill_pr_vectordb.py
```

### Step 2: Generate Issue→PR Links
Generate the reverse mappings (issues to PRs):

```bash
# Generate for 50 most recent issues
python3 generate_issue_pr_links.py --issues 50

# Or generate for more issues
python3 generate_issue_pr_links.py --issues 100
```

### Step 3: Start the Viewers

**Option A: Start PR→Issue Viewer**
```bash
python3 pr_results_viewer.py
# Open http://localhost:5001
```

**Option B: Start Issue→PR Viewer**
```bash
python3 issue_pr_viewer.py
# Open http://localhost:5002
```

**Option C: Run Both Simultaneously**
```bash
# Terminal 1
python3 pr_results_viewer.py

# Terminal 2
python3 issue_pr_viewer.py
```

## 📁 Data Files

| File | Description | Generated By |
|------|-------------|--------------|
| `pr_issue_links.json` | PR → Issues mappings | `pr_monitor_server.py` |
| `issue_pr_links.json` | Issue → PRs mappings | `generate_issue_pr_links.py` |
| `seen_prs.json` | Tracked PR numbers | `pr_monitor_server.py` |
| `chroma_db/` | Redmine issues vector store | `redmine_sync_server.py` |
| `chroma_db_prs/` | GitHub PRs vector store | `pr_monitor_server.py` |

## 🔄 Keeping Data Fresh

### Automatic Updates
Run these servers in the background to keep data current:

```bash
# Terminal 1: Sync Redmine issues every 15 minutes
python3 redmine_sync_server.py

# Terminal 2: Monitor GitHub PRs every 15 minutes
python3 pr_monitor_server.py
```

### Manual Updates
Regenerate issue→PR links periodically:

```bash
python3 generate_issue_pr_links.py --issues 50
```

## 🎯 Use Cases

### Use Case 1: "Which PRs relate to this issue?"
1. Open Issue-PR Viewer (port 5002)
2. Search for your issue number
3. View PRs with >85% similarity

### Use Case 2: "Which issues does this PR address?"
1. Open PR Results Viewer (port 5001)
2. Search for your PR number
3. View all related issues with similarity scores

### Use Case 3: "What's the latest activity?"
1. Both viewers auto-refresh every 60 seconds
2. Or click the 🔄 Refresh button manually

## ⚙️ Configuration

### Change Ports
```bash
# PR Results Viewer
python3 pr_results_viewer.py --port 8080

# Issue-PR Viewer
python3 issue_pr_viewer.py --port 8081
```

### Adjust Similarity Threshold
Edit `issue_pr_viewer.py` line 398:
```python
if pr.get('similarity_score', 0) > 0.85  # Change 0.85 to your threshold
```

### Change Issues Per Page
Edit `issue_pr_viewer.py` line 408:
```python
return filtered_data[:50]  # Change 50 to your desired limit
```

## 🔍 Search Tips

### PR Results Viewer
- Search by PR number: `1234`
- Search by title: `fix memory leak`
- Combine with filters: Search + filter by "Open"

### Issue-PR Viewer
- Search by issue number: `12345`
- Search by subject: `osd crash`
- Partial matches work: `mem` finds "memory leak"

## 📊 Understanding Similarity Scores

- **90-100%**: Very strong match - likely directly related
- **85-90%**: Strong match - probably related
- **80-85%**: Moderate match - possibly related
- **<80%**: Weak match - may not be directly related

The Issue-PR Viewer only shows PRs with >85% similarity to reduce noise.

## 🐛 Troubleshooting

### "No Results Yet"
- Run `generate_issue_pr_links.py` first
- Check that `issue_pr_links.json` exists

### Empty PR List for an Issue
- The issue may not have any PRs with >85% similarity
- Try lowering the threshold in the code

### Viewer Not Updating
- Click the 🔄 Refresh button
- Check that background servers are running
- Regenerate the data files
